# OficioCerca — MVP Web

Primera versión visual y funcional preparada para desplegar en Vercel.

## Ejecutar localmente

Requiere Node.js 18+.

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Desplegar en Vercel

1. Subí esta carpeta a un repositorio de GitHub.
2. Entrá a Vercel.
3. Importá el repositorio.
4. Vercel detectará Next.js automáticamente.
5. Deploy.

## Próximas integraciones

Esta versión es un MVP de frontend. Los botones muestran mensajes de demostración. La siguiente etapa puede conectar:
- PostgreSQL / Supabase
- autenticación
- GPS y mapas reales
- perfiles
- mensajería
- pagos
- cursos
- marketplace
- IA
- paneles de empresas e instituciones
- verificación de profesionales y certificados
